# Architecture

## Targets

| Target | Contents |
| --- | --- |
| `Wave` | The app. Swift 6, SwiftUI, iOS 17.0+. |
| `WaveWidgets` | WidgetKit extension. Now Playing + Wave widgets. No App Groups entitlement in the repo — add `group.app.wave` in Xcode for live data (see README). |
| `WaveTests` | XCTest unit tests, app-hosted. |

The Xcode project is generated by XcodeGen from `project.yml`. Sources are
picked up by directory glob, so a new `.swift` file in the right folder is
in the build with no project edit.

## Layers

```
UI (Screens, Player, Components)
  ↓  binds to @Observable objects, sends user intents
Services (Player, InnerTubeClient, LyricsService, LibraryStore, JamService, ...)
  ↓  plain Swift, mostly actors or @MainActor classes
Apple frameworks (URLSession, AVFoundation, SwiftData, WidgetKit, WKWebView)
```

Rules:

- **Models are plain structs, `Sendable`, `Codable` where stored.** No UIKit
  or SwiftUI types in `Models/`.
- **Services expose protocols** (see `docs/CONTRACTS.md`). The app wires
  concrete implementations in `WaveApp`. Tests use fakes.
- **The player is the only `@MainActor @Observable` service the UI binds
  to.** Everything else posts state through it or through the settings
  store.
- **Concurrency:** network and decode work runs off the main actor.
  `Sendable` is enforced by `SWIFT_STRICT_CONCURRENCY: minimal`, so keep
  shared mutable state inside actors.
- **No third-party dependencies.** Only Apple frameworks. This keeps the
  unsigned CI build reliable and the sideload simple.

## Data flow — playing a song

1. UI calls `Player.play(track)`.
2. Player asks `InnerTubeClient.player(videoId:)` for the stream info
   (adaptive formats, cipher decipher, poToken if the session has one).
3. Player picks the best audio-only format for the current network
   (`NWPathMonitor`: Wi-Fi vs cellular, quality setting).
4. `AVPlayer` (streamed) or `AVAudioEngine` (local file / EQ path) plays it.
   The EQ chain is `AVAudioUnitEQ` + time-pitch unit inside the engine.
5. Lyrics load in parallel from `LyricsService`; the player sheet shows the
   synced line for the current position.
6. Last.fm scrobbles at the halfway point if enabled.

## InnerTube

Base: `https://music.youtube.com/youtubei/v1`. Client `WEB_REMIX`.
Requests are `POST` with a JSON body containing `context.client` and the
endpoint-specific fields. Responses are parsed with `Codable` into the
models in `Models/`. Full endpoint and field reference: `docs/SPECS.md`.

The app never uses `IOS`-family clients for audio URLs: there is no mintable
iOS GVS token, and those URLs fail without one.

## poToken

`PoTokenGenerator` runs the BotGuard challenge in a headless `WKWebView`
and returns `(poToken, visitorData)`. The tokens attach to player requests.
If generation fails, playback continues without a token and YouTube may
reject some streams — the failure is surfaced, not hidden.

## Downloads

`URLSession` background downloads. Files land in the app container under
`Downloads/`, named `<artist> - <title>.<ext>`. Tags are written after the
download (ID3v2.3 for MP3, native metadata for M4A/FLAC), plus a `.lrc`
sidecar when synced lyrics exist. Export uses the document picker — there
is no shared-storage access on iOS.

## Jam (Listen Together)

`URLSessionWebSocketTask` to `wss://jam.clashgram.org/ws`, same JSON
protocol as the Android app (`docs/SPECS.md`). iOS suspends sockets when
the app backgrounds; the socket stays alive while audio plays (background
audio mode). Deep links: `wave://jam?code=…` and
`https://jam.clashgram.org/?code=…`.

## Google Cast — not in this build

Cast needs the Google Cast iOS SDK, which ships via CocoaPods, plus the
local-network and Bonjour entitlements. Adding it means: a `Podfile` with
`google-cast-sdk`, `pod install` in CI, and a `CastManager` wrapping
`GCKSessionManager`. The player UI already has the Cast button slot; it
currently opens a sheet explaining the situation. Do not fake a device list.

## Liquid Glass

iOS 26 `glassEffect` is used behind `#available(iOS 26.0, *)`, with
`.ultraThinMaterial` as the fallback on iOS 17–25. The deployment target
stays iOS 17.0 so older devices keep working.
